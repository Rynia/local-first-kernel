# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

At Rynia Studios, security and data sovereignty are fundamental architectural tenets. 

If you discover a security vulnerability in this package, please do **NOT** open a public issue. Instead, report it privately via email:

* **Security Contact:** `ryniastudios@gmail.com`
* **Subject:** `[SECURITY] Vulnerability Report - {Package Name}`

Please include:
1. Steps to reproduce or proof-of-concept code.
2. Affected versions and environments.
3. Potential impact on local-first storage or execution integrity.

We commit to acknowledging your report within 48 hours and issuing a verified patch release within 7 days.
